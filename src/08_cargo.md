# Cargo 도구 소개

`Rust` 컴파일러는 `rustc`이지만, 실제 개발 현장에서 이를 직접 실행하는 경우는 거의 없습니다. 대신 모든 프로젝트 관리와 빌드 과정을 `cargo`가 담당합니다.

`cargo`는 단순히 컴파일을 돕는 도구가 아니라 프로젝트의 생명주기 전체를 책임지는 강력한 도구입니다.

```bash
$ cargo help
# 주요 명령어 목록과 도움말을 출력합니다.
```

`Rust`에서는 프로젝트를 '패키지'라고 부릅니다. `cargo`는 이 패키지를 관리하는 도구로, 의존성 라이브러리(크레이트, `Crate`) 관리부터 빌드, 테스트, 문서화까지 한 번에 해결해 줍니다.

## 자주 사용하는 명령어

### 1. `cargo new`
새 프로젝트를 생성합니다.
*   `cargo new --bin 프로젝트명`: 실행 파일(바이너리) 프로젝트를 만듭니다.
*   `cargo new --lib 프로젝트명`: 라이브러리 프로젝트를 만듭니다.

### 2. `cargo check`
컴파일이 가능한지 에러만 빠르게 확인합니다. 실제 실행 파일을 생성하지 않기 때문에 `cargo build`보다 훨씬 빠릅니다. 개발 중 문법 에러를 수시로 확인할 때 매우 유용합니다.

### 3. `cargo build`
최종 결과물을 만듭니다.
*   디버그 빌드: `cargo build` (결과물 위치: `target/debug/`)
*   릴리스 빌드: `cargo build --release` (최적화 포함, 결과물 위치: `target/release/`)

### 4. `cargo run`
빌드와 실행을 동시에 수행합니다. 프로그램에 인자를 전달하려면 `--` 다음에 인자를 적습니다.
```bash
$ cargo run -- --help
```

### 5. `cargo add` & `cargo search`
외부 라이브러리([crates.io](https://crates.io))를 검색하고 프로젝트에 추가합니다.
```bash
$ cargo search anyhow
$ cargo add anyhow
```
명령어를 실행하면 `Cargo.toml` 파일의 `[dependencies]` 섹션에 자동으로 라이브러리 정보가 기록됩니다.

### 6. `cargo fmt`
코드를 `Rust` 공식 스타일 가이드에 맞춰 자동으로 정렬해 줍니다. 협업 시 코드 일관성을 유지하는 데 필수적입니다.

### 7. `cargo test`
작성된 테스트 코드를 실행합니다.
*   `src/` 내의 유닛 테스트와 `tests/` 디렉토리의 통합 테스트를 모두 수행합니다.
*   `///` 주석 안에 포함된 예제 코드(문서화 테스트)도 함께 검증합니다.

### 8. `cargo doc`
소스 코드의 주석을 분석하여 세련된 웹 형태의 매뉴얼 사이트를 자동으로 구축해 줍니다.
```bash
$ cargo doc --open
```

## Cargo.toml 파일

패키지의 이름, 버전, 에디션 정보와 함께 프로젝트가 의존하는 외부 크레이트 목록을 관리하는 명세서입니다. `TOML` 포맷을 사용하며, `cargo add` 명령을 통하거나 직접 편집하여 설정을 변경할 수 있습니다.

`cargo`는 `Rust` 생태계를 하나로 묶어주는 핵심적인 도구입니다. 이 도구의 기능을 잘 활용할수록 개발 효율은 비약적으로 상승할 것입니다.
