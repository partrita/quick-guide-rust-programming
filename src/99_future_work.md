# 향후 과제 및 참고 자료

이 책에서 다 다루지 못한 깊이 있는 주제들과 `Rust` 생태계에서 필수로 여겨지는 도구들을 정리했습니다.

## 추천 크레이트

*   `anyhow` / `thiserror`: 실무적인 에러 처리를 위한 필수 라이브러리.
*   `serde` / `serde_json`: 데이터 직렬화 및 역직렬화의 제왕.
*   `clap`: 세련된 커맨드 라인 인터페이스(`CLI`) 제작 도구.
*   `axum` / `actix-web`: 고성능 비동기 웹 프레임워크.
*   `sqlx` / `diesel`: 타입 안전한 데이터베이스 연동 라이브러리.

## 심화 주제: std::pin

자기 참조(`Self-reference`) 구조체를 만들거나 비동기 작업을 깊이 있게 이해하려면 `Pin`의 개념이 필수입니다. 객체가 메모리에서 이동하지 못하도록 고정하는 역할을 합니다.

```rust
// 간단한 예시: Pin된 객체는 메모리 주소가 변하지 않습니다.
let first = MyStructPinned { ... };
let mut first_pin = Box::pin(first); // 힙에 고정(Pin)
```

## 마치며

`Rust` 공부의 가장 좋은 방법은 직접 무언가를 만들어 보는 것입니다. 시리얼 생성기 프로젝트를 확장하거나, 본인에게 필요한 작은 도구를 `Rust`로 개발해 보세요. 컴파일러와 싸우는 시간이 줄어들수록, 여러분은 더 견고하고 빠른 소프트웨어를 만드는 전문가로 거듭날 것입니다.

부족한 글이지만 `Rust`라는 거대한 바다를 항해하는 데 작은 나침반이 되었기를 바랍니다. 감사합니다.
